# CaféStock — Equipo 2 (Escenario A)

Aplicación de escritorio en Java para la gestión de inventario y ventas de la cafetería universitaria (**Escenario A: CaféStock**).

- **Bryan Cheme:** Scrum Master y Desarrollador

## Tecnologías Utilizadas
- **Lenguaje:** Java (JDK)
- **Interfaz Gráfica:** Java Swing
- **Persistencia de Datos:** Archivos CSV
- **Gestión Ágil:** Scrum con tablero en Trello
- **IDE de desarrollo:** IntelliJ IDEA
